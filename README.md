# Go Calculator CLI

A simple command-line calculator built with Go.

## Features

- Addition
- Subtraction
- Multiplication
- Division

## Requirements

- Go 1.24 or later

## Run

```bash
go run .
```

## Example

```
Enter first number: 10
Enter second number: 5

Sum: 15
Difference: 5
Product: 50
Quotient: 2
```
